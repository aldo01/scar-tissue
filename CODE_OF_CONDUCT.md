# Code of conduct

scar-tissue is built from engineers' hardest production lessons. People share incidents, mistakes, and outages here, so this has to be a place where that is safe to do.

## Expected behavior

- Be respectful and assume good intent.
- Critique code and rules, not people.
- Treat shared incidents and war stories as lessons, never as material for blame.
- Welcome newcomers and explain context they might not have.

## Unacceptable behavior

- Harassment, insults, or discriminatory language of any kind.
- Personal attacks, trolling, or sustained disruption.
- Publishing someone's private information, or details of another organization's incident that were shared in confidence.
- Posting working exploits or undisclosed vulnerabilities in other projects. Use private disclosure as described in [SECURITY.md](SECURITY.md).

## Scope

This applies to all project spaces: issues, pull requests, discussions, and any other channel run by the project.

## Enforcement

Report problems privately to the maintainer, [@aldo01](https://github.com/aldo01), through the contact details on their GitHub profile. Reports are kept confidential.

The maintainer may edit or remove comments, close threads, or block contributors who break this code, starting with a warning except for severe cases.
